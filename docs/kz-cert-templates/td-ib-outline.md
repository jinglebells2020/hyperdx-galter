# ТД ИБ (Технические Документы по ИБ) — четырёхуровневая структура

OPOIB §2 п.3 + п.31 ППРК ЕТ требуют, чтобы у Mooldir-as-an-organisation
была документация по ИБ в виде четырёх уровней. Этот файл — шаблон,
который ИБ-офицер заполняет реальными ссылками после оформления.

Документация ведётся на казахском и русском. Утверждается правовым актом
руководителя организации. Пересматривается не реже одного раза в два
года.

## Уровень 1 — Политика ИБ (Information Security Policy)

Одностраничный документ за подписью руководителя.

- Цель и область действия
- Принципы ИБ (CIA + accountability + privacy)
- Ответственность руководства (OPOIB §3 п.8)
- Ссылки на нормативную базу (ЗРК «Об информатизации» №418-V,
  ППРК ЕТ №832, ППРК «Правила мониторинга» №52/НҚ, СТ РК ISO/IEC
  15408-2-2017, СТ РК ISO/IEC 27002-2023)

**Шаблон:** `policy-ib.md`. Утверждается приказом.

## Уровень 2 — Стандарты

Конкретные правила, применимые к классу ОИ:

- Стандарт классификации информации
- Стандарт управления доступом
- Стандарт парольной политики
- Стандарт криптографических методов
- Стандарт ведения журналов ИБ
- Стандарт реагирования на инциденты ИБ
- Стандарт обеспечения непрерывности бизнеса
- Стандарт безопасной разработки ПО (SDL)
- Стандарт работы с поставщиками

**Шаблоны:** `standard-*.md`. Утверждаются ИБ-офицером.

## Уровень 3 — Процедуры

Пошаговые инструкции:

- Процедура регистрации/отмены учётной записи
- Процедура смены пароля + сбросa пароля
- Процедура проведения резервного копирования + восстановления
- Процедура анализа журналов ИБ
- Процедура реагирования на инцидент (детектирование → классификация →
  локализация → восстановление → ретроспектива)
- Процедура управления изменениями (change management)
- Процедура работы с уязвимостями (vulnerability mgmt)
- Процедура утилизации активов
- Процедура физической безопасности серверных помещений
  (распространяется на Railway via наследование SOC 2; документировать
  как deferred-control)

## Уровень 4 — Записи и журналы

Свидетельства выполнения процедур:

- Журнал событий ИБ (HdxAuditEvent в Mongo)
- Журнал инцидентов
- Журнал доступа к серверным помещениям (от Railway / SOC 2)
- Журнал смены паролей (часть HdxAuditEvent)
- Журнал резервного копирования (вывод cron-job)
- Журнал тестов восстановления
- Протоколы пересмотра ТД ИБ (1 раз в 2 года)
- Протоколы обучения персонала по ИБ

## Ответственность

| Уровень | Утверждает | Пересматривает |
|---|---|---|
| 1 — Политика | Руководитель организации | Раз в 2 года |
| 2 — Стандарты | ИБ-офицер | Раз в год |
| 3 — Процедуры | ИБ-офицер совместно с владельцами процессов | По мере необходимости |
| 4 — Журналы | Автоматически Mooldir-системой | Аудит-офицер раз в квартал |
